# 📚 編輯指南 (Beta)

呢篇文件會詳細說明 BNBU 手冊嘅詳細編輯要求同規範，畀所有參與編輯嘅同學參考。

## 前置步驟

你需要有一個 Github 帳號

如果用網頁版編輯，你可以直接喺網頁上面撳編輯同埋一鍵提交 PR

如果用本地編輯，你需要識 Git 相關嘅知識，先 Fork 倉庫，然後 Clone 到本地，編輯完提交到自己嘅分支，再提交 PR

## 提交方法

一般嚟講，所有提交都應透過 Pull Request 合併到 `dev` 分支上面，提交前請先確保你嘅本地倉庫係最新嘅，以免唔必要嘅合併衝突。如果遇到衝突，請去編者所在各聊天軟件度同相關編者溝通。

## 參考資料格式

一般嚟講，參考資料唔要求一定要提供，但如果你喺編輯過程中用咗某啲來源嘅資料，建議你將佢加到文件末尾嘅參考資料部分，畀其他讀者可以驗證同進一步了解相關資訊。

參考資料一般放喺每個 Markdown 文件嘅末尾，格式如下：

呢個格式結合咗 APA 格式同 Wikipedia 嘅參考資料格式，適用於網頁同書籍兩種常見來源。請根據你用嘅來源類型揀相應嘅格式去引用。

**網頁**

```Markdown
(正文)
我校建於2005年[^1]，位於……

(頁尾)
## 參考資料

[^1]: **作者姓名/機構名稱** (發佈年份或者具體日期). *文章/頁面標題*. 網站或者平台名稱. 取自: [原始鏈接](http://example.com) (網頁存檔: [Internet Archive](http://example.com), 存取於 你訪問/存檔嘅日期).

(示例)
[^2]: **宋雪梅** (2020-3-26). *北師港浸大託管會同社區體育公園 不斷開拓產學研合作領域*. 珠江晚報. 取自: [原始鏈接](https://www.bnbu.edu.cn/info/1078/8891.htm) (網頁存檔: [Internet Archive](https://web.archive.org/web/20260419035308/https://www.bnbu.edu.cn/info/1078/8891.htm), 存取於 2026-04-19).
```

渲染效果：  
我校建於2005年[^1]，位於……
